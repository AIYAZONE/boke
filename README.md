# boke

> 播客 · 收录感兴趣的内容

站点：[boke.aiyazone.com](https://boke.aiyazone.com/)　｜　目前收录一档，之后会做成多播客归集站。

当前收录：**YC 斯坦福公开课《如何创业》20 讲 · 中文笔记 + 播客**。

源材料是《如何创业_YC_斯坦福公开课(20集).docx》（约 3.1 万汉字，本身已是一份要点整理）。
这一版在它之上重新整理，并配了一档 6 集、约 30 分钟的中文对谈播客。
读的顺序建议是：先「零基础白话」，再回头用速查页查数字和讲次。

## 读法

速查页按「你正在解决什么问题」组织，10 个标签：

- **播客收听**：点左侧换集，也能下载全集
- **零基础白话**：第一次读从这里开始
- **名词注解**：可搜索的完整词条表
- 五个底层命题 / 七个模型 / 反直觉对照 / 关键数字 / 分级行动清单 / 20 讲索引 / 金句

两个小设计：

- 正文里**带虚线的英文词、人名、公司名点一下就有中文解释**（手机上也能点），完整的词条表在「名词注解」页。
- 「关键数字」默认按创业阶段分成 5 组，语义在前、单位跟着数字给；也可切到按数值或按讲次看。

## 播客分集

两个人聊天（小雅女声 / 老周男声），中文双音色合成，按创业阶段而非课号重排，共约 30 分钟。
这一版按更口语的方式重写过，并把核对后更正的口径同步进了口播。

## 品牌

`brand/预览.html` 可以直接打开看全套素材。站点品牌固定为 `boke · 播客收录`，
每档节目用「编号 + 主色」区分——当前这档是 No.01（橙）。
后续新增播客时，复制 `brand/cover-01-二十讲.svg` 改 `no / title / subtitle / accent` 四个参数即可，版式不动。
详见 `brand/品牌与延展规范.md`。

## 本地使用

克隆或下载后，直接用浏览器打开根目录的 `index.html`：

1. 点左侧分集列表切换音频，或直接播放 `podcast/YC20_full.mp3`
2. 音频用相对路径 `podcast/*.mp3`，需保持 `podcast/`、`brand/` 与 `index.html` 同级
3. 页面无 CDN、无外链字体与脚本，可离线运行；favicon 已内嵌，不依赖外部文件

## 先说清楚适用范围

- 课里讲的是奔着超高速增长去的创业。想开安稳小店、做生活方式型生意，大半建议用不上。
- 案例和数字集中在 2014 年以前，看个量级与判断思路就好，别当今天的统计。
- 特拉华州公司、SAFE、83(b)、合格投资人、W2/1099 这些都是美国法域的实务，换个地方得重新问一遍。

## 技术说明

- 音频：edge-tts 双音色合成，227 段语音拼接，MP3 24 kHz / 单声道。
- 页面：单文件 HTML，纯前端，无外部依赖。
- Logo：矢量 SVG 生成，另导出 PNG；生成脚本见 `scripts/make_brand.py`。
