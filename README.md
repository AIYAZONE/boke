# boke

> 播客 · 收录感兴趣的内容

当前收录：**YC 斯坦福公开课《如何创业》20 讲 · 精华提炼 + 中文播客**。

基于《如何创业_YC_斯坦福公开课(20集)》原始文档（约 7.1 万字）做的**二次优化提炼**，并配套生成一档 6 集、约 41 分钟的中文双人播客。

> 不是原文的搬运，而是压缩、重组、补齐决策工具：从「20 讲按顺序读」重排为「按创业阶段查」。

## 提炼版结构（9 个模块）

1. 30 秒总览
2. 5 个底层命题
3. 7 个可复用模型（含公式与阈值）
4. 5 编结论卡
5. 18 条反直觉对照
6. 45 个关键数字（纯数字列，网页版可点击排序）
7. P0 / P1 / P2 分级行动清单
8. 按问题速查
9. 20 讲一句话索引 + 10 条金句

原书没有、本次补上的三处：**P0/P1/P2 优先级分级**、**可排序数字表**、**使用边界**。

## 本地使用

克隆或下载本仓库后，直接用浏览器打开根目录的 `index.html` 即可：

1. 页面内点击左侧分集列表切换音频，也可直接播放 `podcast/YC20_full.mp3` 全集连播
2. 8 个标签页覆盖底层命题、模型、反直觉对照、关键数字、行动清单等速查内容
3. 音频使用相对路径 `podcast/*.mp3`，需保持 `podcast/` 目录与 `index.html` 同级

页面为单文件、无外部依赖，可完全离线运行。

## 使用边界（重要）

- 结论只适用于 **hyper growth 型创业公司**，不适用于小型生意或稳定期企业。
- 案例与数字多为 **2014 年前口径**，融资额、估值、增长率不可直接套用到当下市场。
- Delaware C-Corp、83(b) election、合格投资人、期权税务等属于**美国法域**，不可照搬到其他国家/地区。

## 技术说明

- 音频：edge-tts 双音色合成，239 段语音拼接，MP3 24 kHz / 单声道，平均音量约 −22.5 dB，已做静音检测。
- 页面：单文件 HTML，无外部依赖（无 CDN、无外链字体/脚本），纯前端可离线运行。
